# tmux-osc-filter

One-line install on Linux x86_64:

```bash
curl -fsSL https://github.com/andjohnsonj5/tmux-osc-filter/releases/download/tmux-binary-20260505-0005/tmux-binary-20260505-0005-linux-x86_64.tar.gz | tar -xzO tmux-binary-20260505-0005/tmux-linux-x86_64 | sudo tee /usr/local/bin/tmux >/dev/null && sudo chmod 755 /usr/local/bin/tmux
```

Verify:

```bash
tmux -V
```
